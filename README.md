**Smart Habit Consistency Tracker**

A web application that helps users track daily habits and maintain consistency.
Users can create habits, mark them as completed, and monitor their progress through a dashboard with visual charts.

**Features:**
User registration and login

Add and manage daily habits

Mark habits as completed

Dashboard displaying habit progress

Pie chart and consistency graph for visualization

Set reminder time for habits

**Technologies Used:**

Python

Flask

HTML

CSS

Bootstrap

JavaScript

Jinja2

**Future Improvements:**

Database integration (MySQL)

Email reminder system

Habit streak tracking

Mobile responsiveness
